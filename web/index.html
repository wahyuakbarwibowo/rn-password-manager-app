Fitur Utama

Sepenuhnya Offline

Data Anda tidak pernah meninggalkan perangkat. Tidak ada koneksi internet atau server yang terlibat.

Enkripsi AES-256-GCM

Kata sandi dan catatan dienkripsi dengan kunci AES-256-GCM yang tersimpan di Android Keystore perangkat.

Unlock Biometrik

Buka kunci vault dengan sidik jari atau wajah, dengan penguncian otomatis saat aplikasi tidak digunakan.

Keamanan Aplikasi

Gunakan aplikasi ini dengan percaya diri untuk menyimpan kata sandi Anda. Aplikasi ini berjalan sepenuhnya offline, sehingga data Anda tidak pernah meninggalkan perangkat.

Mengapa Aman?

  • 100% Offline - Data tersimpan lokal di perangkat Anda, tidak ada koneksi internet yang diperlukan
  • Tidak Ada Server - Tidak ada data yang dikirim ke server atau cloud
  • Enkripsi AES-256-GCM - Kata sandi dan catatan dienkripsi dengan kunci hardware-backed dari Android Keystore
  • Master Password - Diverifikasi dengan PBKDF2 (100.000 iterasi); hanya Anda yang tahu master password untuk membuka vault

Penting: Pastikan Anda tidak lupa master password! Karena tidak ada server atau cloud, tidak ada cara untuk mereset atau memulihkan master password yang terlupa.
